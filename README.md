# 📱 Projeto Aplicativo Mobile

Projeto de desenvolvimento de um aplicativo mobile.

---

## 🎯 Objetivo do Projeto

Desenvolver um aplicativo mobile para gerenciamento de profissionais,
clientes, serviços e agendamentos.

O sistema terá funcionalidades relacionadas ao cadastro de clientes,
cadastro de serviços, gerenciamento de agenda e histórico de atendimentos.

## 📅 Rafael — Agenda e Funcionalidades Principais

Responsável pelo gerenciamento dos agendamentos e pelas principais
funcionalidades relacionadas à agenda do aplicativo.

### Agenda

- Criar novo agendamento;
- Selecionar cliente;
- Selecionar serviço;
- Selecionar data;
- Selecionar horário;
- Inserir endereço;
- Inserir observações;
- Alterar agendamento;
- Cancelar agendamento.

### Histórico

Quando o profissional concluir um serviço, o atendimento deverá
aparecer no histórico.

### Entregáveis

- Sistema de agendamento funcionando;
- Controle de horários;
- Alteração de status;
- Histórico de atendimentos;
- Integração com banco de dados.

## 🧪 Luis — Testes, Documentação e Qualidade

Responsável por testar o aplicativo, validar as funcionalidades,
identificar problemas e organizar a documentação final.

### Testes funcionais

#### Cadastro

- Criar conta;
- Fazer login;
- Acessar o Dashboard.

#### Cliente

- Cadastrar cliente;
- Salvar cliente;
- Consultar cliente.

#### Serviço

- Cadastrar serviço;
- Salvar serviço;
- Consultar serviço.

#### Agendamento

- Criar agendamento;
- Verificar se o agendamento aparece na agenda.

#### Conclusão

- Alterar agendamento para "Em andamento";
- Alterar agendamento para "Concluído";
- Verificar se o atendimento aparece no histórico.

### Testes de erros

Serão verificados problemas como:

- Cadastro com campos vazios;
- Horário inválido;
- Agendamento duplicado;
- Cliente inexistente;
- Serviço inexistente;
- Exclusão indevida;
- Dados que não são salvos;
- Aplicativo fechando inesperadamente;
- Problemas de navegação.

### Documentação

- Manual de utilização;
- Descrição das funcionalidades;
- Casos de teste;
- Evidências dos testes;
- Problemas encontrados;
- Correções realizadas;
- Documentação para apresentação.
